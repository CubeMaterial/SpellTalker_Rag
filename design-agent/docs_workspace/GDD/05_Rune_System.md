## 3. 핵심 규칙

- 룬은 카드/스펠과 분리된 별도 덱 구조로 관리한다.
- 룬 없이 핵심 전투가 성립하는 구조는 피한다.
- 단일 조합만 반복하는 압도적 최적해를 만들면 안 된다.
- 1룬 조합은 단순하고 안정적이어야 한다.
- 2룬 조합은 핵심 전술 단계여야 한다.
- 3룬 조합은 강력하지만 준비 비용이 커야 한다.

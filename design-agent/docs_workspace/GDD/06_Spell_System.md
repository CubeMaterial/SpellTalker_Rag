# Spell System

## 1. 목적

이 문서는 `06_Spell_System.md`에 해당하는 `Spell System` 영역을 정리한다. 기존 문서에서 확인된 기준: 스펠 사용에 필요한 자원.

## 2. 현재 확정된 내용

- 스펠 사용에 필요한 자원.
- 스펠을 구성하는 기본 요소.
- Spell
- 룬 조합으로 발동되는 효과.
- 카드 및 스펠과 별도로 존재한다.
- 카드, 스펠, 액션이 영향을 미치는 대상.
- 1룬 조합은 단순하고 안정적이어야 한다.
- 2룬 조합은 핵심 전술 단계여야 한다.
- 3룬 조합은 가장 강력하지만 준비 비용이 커야 한다.
- Spell Design Rules
- 스펠이 주요 딜링 수단이어야 한다.
- 고위험 고보상 조합을 일부 포함한다.
- 특정 스펠 하나만 반복해서 쓰는 구조는 피한다.
- 마나 수급 속도는 룬 운용과 스펠 사용 템포를 압도하면 안 된다.
- 초반은 단순, 후반은 조합형 운영이 되도록 설계한다.
- 시너지 조합은 허용하되, 전투를 즉시 무력화하면 안 된다.
- 단일 조합만 반복하는 압도적 최적해
- Milestone 4 - Spell System
- 룬 1~3개 조합 가능
- 조합 결과 스펠 생성 가능
- 스펠 발동 가능
- [ ] SpellData
- [ ] SpellSystem
- 룬 스펠은 준비 단계에서 예약할 수 있다.
- 예약한 스펠은 실시간 전투가 진행되면 캐스팅을 시작한다.
- 예약한 스펠은 취소하거나 다른 스펠로 교체할 수 있다.
- 이미 캐스팅 중인 스펠이 있다면 다른 스펠 예약은 불가하다.
- 캐스팅이 완료되면 룬 스펠이 발동한다.

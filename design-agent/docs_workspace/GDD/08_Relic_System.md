## 2. 현재 확정된 내용

- 장비와 유물은 전투 시작, 준비 단계, 턴 종료 등 특정 타이밍에 능력치 변동이나 기능을 수행할 수 있다.
- 장비와 유물은 얼리 액세스 이후 개발 범위로 우선 보류한다.


## 3. 핵심 규칙

- 장비/유물 효과는 카드, 룬, 스펠의 기본 책임을 직접 대체하지 않는다.
- 전투 중 적용 타이밍을 명확히 분리한다.

## 4. 플레이 흐름

- 전투 시작/준비 단계/턴 종료 등 지정된 타이밍에 장비와 유물 효과를 적용한다.

## 5. 데이터 구조

|---|---|---|
| EquipmentData | 장비 정적 데이터 | 원문 초안 분리 |
| RelicData | 유물 정적 데이터 | 원문 초안 분리 |

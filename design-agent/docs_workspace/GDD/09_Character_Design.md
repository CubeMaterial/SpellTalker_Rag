## 2. 현재 확정된 내용

- CharacterBase는 캐릭터와 적의 공통 요소를 정의한다.
- 캐릭터와 적은 체력이 0이 되면 사망한다.
- 전투 시작 전 캐릭터/적 상태를 초기화한다.
- 피해 적용 함수는 체력을 깎고 0 이하가 되면 사망 처리한다.
- 턴 시작/턴 종료 함수는 해당 시점에 정의된 기능을 수행한다.
- 플레이어블 캐릭터는 총 6명을 목표로 하며, 프로토타입에는 1명을 우선 제작한다.
- 캐릭터마다 4가지 특성을 가지며, 해금 조건은 단계별 개발 범위에 맞춰 확정한다.


## 3. 핵심 규칙

- 정적 캐릭터 데이터와 전투 중 런타임 상태를 분리한다.
- 특성 해금/선택 규칙은 캐릭터 설계 문서에서 관리한다.

## 4. 플레이 흐름

- 전투 시작 전 초기화 -> 전투 중 피해/상태 변화 -> 턴 시작/종료 처리 순서로 캐릭터 런타임을 갱신한다.

## 5. 데이터 구조

| 항목 | 설명 | 비고 |
|---|---|---|
| CharacterBase | 캐릭터와 적의 공통 전투 요소 | 원문 초안 분리 |
| CharacterData | 플레이어블 캐릭터의 정적 데이터 | 원문 초안 분리 |
| TraitData | 캐릭터 특성 데이터 | 원문 초안 분리 |

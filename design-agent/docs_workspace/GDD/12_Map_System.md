## 2. 현재 확정된 내용

- Node
- 맵 위에서 플레이어가 선택하는 진행 지점.
- Battle Node
- 일반 전투가 발생하는 노드.
- Elite Node
- 강한 적과 전투하는 노드.
- Rest Node
- 회복 또는 강화를 수행하는 노드.
- Shop Node
- 카드 구매, 제거, 강화 등을 수행하는 노드.
- Boss Node
- 던전 마지막에 배치되는 보스 전투 노드.
- Map System
- 프로토타입에는 기본 맵 진행이 포함된다.
- 플레이어는 노드를 선택하며 던전을 진행한다.
- Node Types
- Node Progression
- 현재 노드에서 연결된 다음 노드 중 하나를 선택한다.
- Boss Node를 클리어하면 던전이 종료된다.
- 맵 진입
- 휴식 / 상점 / 보스 노드 이동
- Milestone 5 - Reward / Map Loop

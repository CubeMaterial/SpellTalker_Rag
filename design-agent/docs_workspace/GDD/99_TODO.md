# 1. 프로젝트 개요

-   장르 : 로그라이크 덱빌딩 RPG
-   엔진 : Unity
-   프로젝트명 : SpellTalker
-   플랫폼 : PC (우선 개발)
-   전투 방식 : 실시간 + 준비(Preparation) 시스템

핵심 구조

    카드 사용
    → 마나 획득
    → 룬 조합
    → 스펠 생성
    → 스펠 발동

------------------------------------------------------------------------

# 2. 핵심 컨셉

기존 덱빌딩처럼 카드가 직접 공격하는 게임이 아니다. 
카드는 전투를 준비하는 자원이며, 실제 공격은 룬 조합으로 생성한 스펠이
담당한다. 
=> 카드의 용도 중 하나는 적 공격도 있음. 즉, 카드, 룬 스펠, 액션의 조합으로 적을 쓰러트리는 것이 게임의 핵심임
또한 마나 뿐만 아니라 특정 카드에는 마법진이라는 특수 자원도 얻을 수 있으며 카드나 룬 조합의 코스트로도 사용됨

플레이어는

-   어떤 카드를 사용할지
-   어떤 룬을 조합할지
-   어떤 장비를 장착하고 
-   어떤 액션을 사용할지
-   언제 시전할지


를 판단하는 것이 핵심 전략이다.
여기에서 장비와 마법진, 유물은 E에서 개발하도록 함.

# 3. 전투 흐름

1.  전투 시작
    - 전투 시작 시, 특성, 장비, 유물, 스탯에 따라 적용할 능력치 변동 및 기능 수행   
2.  준비 단계
    1) 카드 드로우
        - 카드 드로우는 손 패에 5장이 되도록 뽑는다. 
        - 5장 이상을 들고 있을 경우 1장만 뽑는다. 
        - 덱에 카드가 없을 경우 뽑아야 하는 장 수만큼 피해를 입는다.   
    2) 준비 단계에서 특성, 장비, 유물, 스탯에 따라 적용할 능력치 변동 및 기능 수행
    3) 유저의 액션
        - 카드를 사용 > 선 딜레이 없이 바로 사용이 가능하며 사용한 카드는 묘지로 간다. 카드의 기능 수행을 큐에 쌓고 순차적으로 사용한다. 
        - 룬 스펠을 사용 > 바로 사용이 불가능하며 스펠 예약 상태에 돌입. 실시간 전투가 진행되면 그 때부터 캐스팅이 들어감. 예약한 스펠을 취소하거나 다른 스펠로 교체가 가능하다. 이미 캐스팅 중인 스펠이 있다면 다른 스펠 예약 불가.
    4) 적의 액션
        - 적의 머리 위에 아이콘으로 행동을 미리 예측 할 수 있으며 기대 데미지를 보여줘서 유저가 반응 할 수 있게 한다.
        - 유저의 룬 스펠과 마찬가지로 예약의 개념으로 준비 단계에선 적은 특정한 상태가 아닌 이상 행동 할 수가 없다.    
3.  실시간 전투 진행
    1) 캐스팅
        - 예약을 걸었거나 이전 턴에 캐스팅 중이었던 스펠이 있으면 남은 캐스팅이 진행
        - 캐스팅이 완료 되었으면 룬 스펠 발동.
    2) 카드 사용
        - 선 딜레이가 있다.
        - 캐스팅 도중에도 카드 사용 가능
        - 액션 중에는 카드 사용 불가
    3) 액션
        - 선 딜레이가 있다.
        - 한 턴에 한 번씩 사용할 수 있음.
        - 미리 등록한 액션 칸 중 하나를 선택한다.
        - 요구 자원은 없으나 쿨타임이 존재
    4) 적의 전투 
        - 적은 AI에 따라 유저를 공격한다.
        - 예약된 액션을 수행한다.
        - 액션이 끝나면 다음 액션에 대한 아이콘을 보여준다.
        - 모든 액션에는 선 딜레이가 존재한다.
4.  턴 종료
    1) 특성, 장비, 유물, 스탯에 따라 적용할 능력치 변동 및 기능 수행 
    2) 카드 재생
        - 무덤에 간 카드들은 재생 수치를 1씩 상승한다. 
        - 카드마다 지정된 재생 완료 값에 도달하면 덱 맨 아래로 들어간다.
    3) 버프, 디버프 적용
        - 버프, 디버프 중 턴 종료 시에 발동하는 것이 있다면 수행한다.
        - 제한 시간이 있다면 1을 깎고 0이 되면 종료한다.
    4) 턴 카운트를 1 올리고 준비 단계로 되돌아간다.   
5. 전투 종료
    - 유저 혹은 적 전체의 체력이 0이 되었을 시 전투가 종료된다.
    - 유저의 체력이 0이 될 시 게임 오버가 된다.
    - 적 전체의 체력이 0이 될 시 아래를 수행한다.
    - 적 종류(일반, 엘리트, 보스)를 체크하고 저장한다
    - 적 종류에 따른 골드와 보상(카드)를 얻는다.
    - 맵으로 되돌아간다.

# 4. 주요 시스템

## 카드

-   마나 생성
-   버프
-   디버프
-   드로우
-   보조 효과
-   공격
-   마법진 생성

## 룬

-   별도의 룬 덱 운영
-   최대 손패 5개
-   1\~3개 조합

## 스펠

-   룬 조합으로 생성
-   성공/실패/치명 성공/치명 실패 판정(E에서 개발)

## 능력치

-   힘
    - 전투 종료 시, 힘 3당 1의 부상 회복
    - 액션 시, 1당 0.01초의 선 딜레이 감소
    - 특정 스펠 중 효과가 힘 비례함
-   민첩
    - 실시간 전투에서 카드 사용 시 1당 0.01초의 선 딜레이 감소
    - 실시간 전투에서 4당 1의 회피율 상승
    - 특정 스펠 중 효과가 민첩 비례함
-   지능
    - 실시간 전투에서 캐스팅 시 1당 0.02초의 딜레이 감소
    - 턴 종료 시 3당 1의 마나를 회복
    - 특정 스펠 중 효과가 지능 비례함
-   행운
    - 성공/실패/치명 성공/치명 실패 판정에 유리하도록 함(E에서 개발)
> 위의 능력치 정의는 추후에 변경 될 수 있음

## HP / 부상

-   HP(체력)와 부상을 분리
-   일부 캐릭터는 부상을 활용
-   전투 시작 시, 최대 체력을 부상만큼 깎고 시작. 예를 들어 최대 체력이 100이고 부상이 20이라면 전투 시작 시, 최대 체력은 80으로 고정. 체력을 회복해도

# 10. CharacterBase

- 캐릭터와 적의 공통적인 요소를 정의한다.
- 체력 : 0이 되면 사망
- 초기화 함수 : 전투 시작 전, 캐릭터의 상태를 초기화한다. 
- 피해 적용 함수 : 피해를 입을 시, 체력을 깎는다. 0이 되면 사망 처리 한다.
- 턴 시작, 턴 종료 함수 : 턴 시작과 종료할 시, 정의된 기능을 수행


# 10. 캐릭터

- 총 6명의 플레이어블 캐릭터를 만들 예정
- 프로토타입에는 1명만 제작
- E에는 3명을 제작
- L에는 전부 다 제작

# 11. 특성

- 캐릭터마다 4가지 특성이 있으며 3종류는 해금 상태이고 3종류를 선택하여 엔딩을 보면 마지막 특성이 해금 된다.(P에 개발)
- 마지막 특성을 들고 있어야 최종 보스 진입 가능(1회차). 마지막 특성으로 최종 보스를 잡으면 어떤 특성이라도 상관없이 최종 보스 돌입 가능(L에 개발)


# 12. 적

- 일반, 엘리트, 보스가 존재
- 한 층의 보스를 쓰러트리면 다음 층으로 이동하다.
- 1층에서 보스를 쓰러트리면 윗층과 아래층으로 갈 수 있는 분기가 주워짐(E에 개발)

        - 유저의 룬 스펠과 마찬가지로 예약의 개념으로 준비 단계에선 적은 특정한 상태가 아닌 이상 행동 할 수가 없다.    
3.  실시간 전투 진행
    1) 캐스팅
        - 예약을 걸었거나 이전 턴에 캐스팅 중이었던 스펠이 있으면 남은 캐스팅이 진행
        - 캐스팅이 완료 되었으면 룬 스펠 발동.
    2) 카드 사용
        - 선 딜레이가 있다.
        - 캐스팅 도중에도 카드 사용 가능
        - 액션 중에는 카드 사용 불가
    3) 액션
        - 선 딜레이가 있다.
        - 한 턴에 한 번씩 사용할 수 있음.
        - 미리 등록한 액션 칸 중 하나를 선택한다.
        - 요구 자원은 없으나 쿨타임이 존재
    4) 적의 전투 
        - 적은 AI에 따라 유저를 공격한다.
        - 예약된 액션을 수행한다.
        - 액션이 끝나면 다음 액션에 대한 아이콘을 보여준다.
        - 모든 액션에는 선 딜레이가 존재한다.
4.  턴 종료
    1) 특성, 장비, 유물, 스탯에 따라 적용할 능력치 변동 및 기능 수행 
    2) 카드 재생
        - 무덤에 간 카드들은 재생 수치를 1씩 상승한다. 
        - 카드마다 지정된 재생 완료 값에 도달하면 덱 맨 아래로 들어간다.
    3) 버프, 디버프 적용
        - 버프, 디버프 중 턴 종료 시에 발동하는 것이 있다면 수행한다.
        - 제한 시간이 있다면 1을 깎고 0이 되면 종료한다.
    4) 턴 카운트를 1 올리고 준비 단계로 되돌아간다.   
5. 전투 종료
    - 유저 혹은 적 전체의 체력이 0이 되었을 시 전투가 종료된다.
    - 유저의 체력이 0이 될 시 게임 오버가 된다.
    - 적 전체의 체력이 0이 될 시 아래를 수행한다.
    - 적 종류(일반, 엘리트, 보스)를 체크하고 저장한다
    - 적 종류에 따른 골드와 보상(카드)를 얻는다.
    - 맵으로 되돌아간다.

-   힘

    - 액션 시, 1당 0.01초의 선 딜레이 감소

-   민첩
    - 실시간 전투에서 카드 사용 시 1당 0.01초의 선 딜레이 감소
    - 실시간 전투에서 4당 1의 회피율 상승
    - 특정 스펠 중 효과가 민첩 비례함
-   지능
    - 실시간 전투에서 캐스팅 시 1당 0.02초의 딜레이 감소
    - 턴 종료 시 3당 1의 마나를 회복
    - 특정 스펠 중 효과가 지능 비례함
-   행운
    - 성공/실패/치명 성공/치명 실패 판정에 유리하도록 함(E에서 개발)
> 위의 능력치 정의는 추후에 변경 될 수 있음

# 10. CharacterBase

- 캐릭터와 적의 공통적인 요소를 정의한다.
- 체력 : 0이 되면 사망
- 초기화 함수 : 전투 시작 전, 캐릭터의 상태를 초기화한다. 
- 피해 적용 함수 : 피해를 입을 시, 체력을 깎는다. 0이 되면 사망 처리 한다.
- 턴 시작, 턴 종료 함수 : 턴 시작과 종료할 시, 정의된 기능을 수행


# 10. 캐릭터

- 총 6명의 플레이어블 캐릭터를 만들 예정
- 프로토타입에는 1명만 제작
- E에는 3명을 제작
- L에는 전부 다 제작

# 11. 특성

- 캐릭터마다 4가지 특성이 있으며 3종류는 해금 상태이고 3종류를 선택하여 엔딩을 보면 마지막 특성이 해금 된다.(P에 개발)
- 마지막 특성을 들고 있어야 최종 보스 진입 가능(1회차). 마지막 특성으로 최종 보스를 잡으면 어떤 특성이라도 상관없이 최종 보스 돌입 가능(L에 개발)


# 12. 적

- 일반, 엘리트, 보스가 존재
- 한 층의 보스를 쓰러트리면 다음 층으로 이동하다.
- 1층에서 보스를 쓰러트리면 윗층과 아래층으로 갈 수 있는 분기가 주워짐(E에 개발)

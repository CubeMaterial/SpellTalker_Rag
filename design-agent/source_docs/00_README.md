# ReadMe

# Deck Roguelike Prototype

Slay the Sprie에서 영감을 받은 반턴제 덱 빌딩 로그라이크 게임이다.

 전체 범위와 프로토타입 범위를 나눠서 명시한다.

일단, 나는 프로토타입을 먼저 개발하고자 한다.

## Stack

- Unity (C#)
- ScriptableObject-based data
- Single player only

## Total Scope

- 10개 층으로 나눠진 던전
- 총 7명의 Playerble Character
- 백과사전 시스템
- 장비 시스템
- 유물 시스템
- 전투 시스템
- 대화 시스템
- 보상 시스템
- 상점 시스템
- 맵
- 적 AI
- 보스는 각 층 당 3종류가 등장

## Prototype Scope

- 지상1층~지상2층까지(가능하다면 3층까지)
- 1 명의 Playerable Character
- 백과사전 시스템
- 유물 시스템
- 전투 시스템
- 대화 시스템
- 보상 시스템
- 상점 시스템
- 맵
- 적 AI
- 보스는 각 층 당 1종류가 등장

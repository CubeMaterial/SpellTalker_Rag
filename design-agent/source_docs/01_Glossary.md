# Glossary
## Card Deck
카드가 저장된 드로우 더미.

## Hand
플레이어가 현재 사용할 수 있는 카드 목록.

## Discard Pile
사용된 카드가 이동하는 더미.

## Regeneration
카드가 Discard Pile에서 다시 Card Deck으로 돌아오는 메커니즘.

## Regen Count
카드가 Card Deck으로 복귀하기까지 남은 턴 수.

## Exhaust
카드가 현재 전투 중 다시 사용할 수 없도록 완전히 제거되는 상태.

## Mana
스펠 사용에 필요한 자원.
주로 카드 사용을 통해 획득한다.

## Rune
스펠을 구성하는 기본 요소.
룬은 별도의 덱 구조로 관리된다.

## Rune Deck
룬이 저장된 드로우 더미.

## Rune Hand
플레이어가 현재 사용할 수 있는 룬 목록.

## Rune Discard Pile
사용된 룬이 이동하는 더미.

## Spell
룬 조합으로 발동되는 효과.
주요 공격 및 전투 효과의 중심 수단이다.

## Action
캐릭터가 사용하는 별도의 능력 슬롯 기반 스킬.
카드 및 스펠과 별도로 존재한다.

## Cooldown
Action 또는 특정 능력을 다시 사용하기까지 필요한 턴 수.

## Target
카드, 스펠, 액션이 영향을 미치는 대상.

## Intent
적이 다음에 수행할 행동 정보.

## Buff
대상에게 유리한 상태 효과.

## Debuff
대상에게 불리한 상태 효과.

## Injury
누적된 손상 상태.
일부 스킬이나 시스템에서 별도로 참조할 수 있다.

## Node
맵 위에서 플레이어가 선택하는 진행 지점.

## Battle Node
일반 전투가 발생하는 노드.

## Elite Node
강한 적과 전투하는 노드.
보상이 더 좋다.

## Rest Node
회복 또는 강화를 수행하는 노드.

## Shop Node
카드 구매, 제거, 강화 등을 수행하는 노드.

## Boss Node
던전 마지막에 배치되는 보스 전투 노드.

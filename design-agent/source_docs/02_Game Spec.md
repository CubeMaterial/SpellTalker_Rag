# Game Spec
- 상태 효과는 중첩 가능하다.
- 각 상태 효과는 개별 규칙을 가진다.
- 상태 효과끼리 상호작용할 수 있다.

예시:
- 가속: 속도 증가
- 냉기: 속도 감소
- 젖음 + 냉기 → 빙결

---

## Injury System
- Injury는 일반 HP와 별도로 추적되는 누적 손상 상태다.
- 일부 스킬이나 효과는 Injury를 참조하거나 소비할 수 있다.
- 회복보다 관리 중심의 리소스로 다룬다.

---

## Battle Rules

### Victory
- 전투 중 모든 적을 처치하면 승리한다.

### Defeat
- 플레이어 HP가 0 이하가 되면 패배한다.

### Reward
전투 승리 후:
- 카드 보상 선택
- 골드 또는 기타 자원 획득
- 추가 보상 처리 가능

---

## Map System
프로토타입에는 기본 맵 진행이 포함된다.
플레이어는 노드를 선택하며 던전을 진행한다.

### Node Types
- Battle Node
- Elite Node
- Rest Node
- Shop Node
- Boss Node

---

### Node Progression
- 현재 노드에서 연결된 다음 노드 중 하나를 선택한다.
- Boss Node를 클리어하면 던전이 종료된다.

---

### Rest Node
플레이어는 다음 중 하나를 선택할 수 있다.
- HP 회복
- 카드 강화

---

### Shop Node
플레이어는 다음 행동을 할 수 있다.
- 카드 구매
- 카드 제거
- 카드 강화
- 기타 제한된 상품 구매

프로토타입에서는 단순화된 상점 구조를 사용한다.

---

## Prototype Completion Condition
프로토타입은 아래가 가능해야 완료로 본다.
- 맵 진입
- 전투 진입
- 카드 사용
- 마나 획득
- 룬 드로우 및 조합
- 스펠 발동
- 전투 승패 판정
- 전투 보상 획득
- 휴식 / 상점 / 보스 노드 이동
- 던전 1회 완주
